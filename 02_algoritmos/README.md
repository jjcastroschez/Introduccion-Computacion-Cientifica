# 🧠 Tema 2: Algoritmia 🧩

En este tema aprenderás a **pensar antes de programar**. La idea es simple: antes de escribir una sola línea de código, debes ser capaz de describir la solución de un problema de forma clara, ordenada y verificable.

Un buen programador no se define por lo rápido que teclea, sino por su capacidad de **diseñar soluciones correctas**.

---

## 📖 Contenido del Tema

### 🧩 ¿Qué es un algoritmo?
Un **algoritmo** es una secuencia **clara y ordenada** de pasos o instrucciones para resolver un problema o realizar una tarea específica.

Verás que un algoritmo:
- puede partir de *cero o más datos de entrada*,
- puede construir *datos intermedios*,
- y produce *al menos una salida* (que puede o no ser un dato).

### ✅ Propiedades de un buen algoritmo
Trabajaremos las propiedades que hacen que un algoritmo sea “bueno” (precisión, ausencia de ambigüedad, finitud, etc.) y aprenderás a detectar errores típicos: pasos vagos, condiciones incompletas o procesos que podrían no terminar.

### 🧾 Cómo representar un algoritmo
Un algoritmo se puede expresar de muchas formas. En este tema aprenderás dos representaciones fundamentales:
- **Pseudocódigo**: una forma estructurada y “cercana al código”, pero independiente del lenguaje.
- **Diagramas de flujo**: representación gráfica mediante símbolos estándar.

Además, relacionaremos estas representaciones con una idea clave: según el **teorema de la programación estructurada**, cualquier programa puede construirse combinando tres estructuras de control: **secuencia, selección e iteración**.

### 🧭 Del problema al programa
Cerramos el tema con una mini-metodología que aplicarás durante todo el curso:
1. **Análisis** del problema (entrada/salida, restricciones, casos),
2. **Diseño** del algoritmo,
3. **Implementación** en el lenguaje elegido,
4. **Selección** del lenguaje y herramientas más apropiados.

---

## 🎯 Objetivos de Aprendizaje

### 1. Fundamentos (El "Qué" y el "Por qué")
- **Definir** qué es un algoritmo y reconocer sus componentes (entradas, intermedias, salidas).
- **Identificar** las características que debe cumplir un algoritmo para considerarse correcto y útil.
- **Distinguir** entre algoritmo, programa y lenguaje de programación.

### 2. Representación (El "Cómo se expresa")
- **Escribir** algoritmos en pseudocódigo con estructura y legibilidad.
- **Representar** algoritmos mediante diagramas de flujo usando símbolos estándar y respetando restricciones.

### 3. Capacidad aplicada (El "Cómo se usa")
- **Diseñar** algoritmos para problemas sencillos de cálculo y decisión.
- **Comparar** distintas soluciones para un mismo problema, razonando sobre simplicidad y eficiencia.

---

## ✅ Resultados de Aprendizaje

Al finalizar el tema, serás capaz de:

- [ ] **Describir** un problema en términos de entrada/salida y pasos necesarios.
- [ ] **Diseñar** un algoritmo correcto y finito para problemas sencillos.
- [ ] **Expresar** el algoritmo en pseudocódigo y en un diagrama de flujo.
- [ ] **Justificar** por qué tu algoritmo es claro, ordenado y ejecutable.
