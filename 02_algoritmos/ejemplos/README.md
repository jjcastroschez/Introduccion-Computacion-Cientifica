# 🐍 Ejemplos - Tema 2: Algoritmia

En esta carpeta encontrarás **scripts de Python** que implementan algunos algoritmos del tema.

> [!NOTE]
> Algunos ejemplos incluyen estructuras (`if`, `while`, `for`) que se estudiarán con detalle en el **Tema 4**.  
> En el Tema 2, el objetivo no es dominar Python todavía, sino ver cómo un **algoritmo** se traduce a un **programa**.

## Contenido
- `01_area_circulo.py`: algoritmo secuencial simple.
- `02_suma_1_a_n.py`: comparación de dos algoritmos (bucle vs fórmula).
- `03_maximo_tres.py`: selección para obtener el máximo.
- `04_mcd_euclides.py`: algoritmo clásico (Euclides) con iteración.
