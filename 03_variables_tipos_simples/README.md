# 🧠 Tema 3: Tipos de Datos y Variables 🔤

En este tema aprenderás **cómo se representa la información dentro de un ordenador**, qué entiende realmente la máquina y cómo los lenguajes de programación (p.e. Python o C) te permiten manipular datos mediante **tipos**, **operadores** y **variables**.

Aquí empezarás a escribir tus primeros fragmentos de código con una base sólida: sabiendo qué tipo tiene cada dato, cómo operan entre sí, cómo convertirlos cuando sea necesario y cómo almacenarlos y hacer referencia ellos.

Este conocimiento te acompañará durante todo el curso… y durante toda tu vida cuando realices tareas de programador 😜.

---

## 📚 Contenido del Tema

### 🔤 ¿Qué es un tipo de dato?

Un **tipo de dato** define:
- el **dominio de valores**,
- las **operaciones permitidas**,
- y su **representación interna**.

Trabajamos desde la base: bits, bytes, enteros, reales, booleanos y cadenas.

### 🧮 Operadores y precedencia

Dominarás los operadores disponibles en Python y C:
- aritméticos: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- booleanos: `and`, `or`, `not`
- relacionales: `==`, `!=`, `<`, `<=`, `>`, `>=`

Además, aprenderás a evaluar correctamente expresiones con **reglas de precedencia** y paréntesis.

### 📌 Variables e identificadores

Responderemos a preguntas clave:
- ¿Qué es una variable?
- ¿Qué significa que Python es de “tipado dinámico” o C de “tipado estático”?
- ¿Cómo se nombran correctamente los identificadores?

También veremos estilos de nombrado (snake_case, camelCase), errores comunes y buenas prácticas.

### 🔄 Conversión de tipos (casting)

Aprenderás a usar:
- `int()`, `float()`, `str()` en Python  
- conversiones explícitas en C  

Analizaremos cuándo un casting (conversión de tipo) es seguro y cuándo puede producir pérdida de información.

### ⌨️ Entrada / salida de datos

Aprenderás a usar:
- `input()` y `print()` en Python,
- `scanf()` y `printf()` en C.

Con ejemplos sencillos que podrás ejecutar y modificar.

---

## 🎯 Objetivos de Aprendizaje

Al finalizar este tema serás capaz de:

### 1. Fundamentos (el “qué” y el “por qué”)
- **Entender** cómo se representa la información en un ordenador.
- **Reconocer** los tipos primitivos en lenguajes como Python y C.
- **Distinguir** entre tipado estático y dinámico.

### 2. Representación (el “cómo se expresa”)
- **Evaluar** expresiones usando operadores y precedencia.
- **Nombrar** variables e identificadores correctamente.
- **Aplicar** buenas prácticas de legibilidad.

### 3. Capacidad aplicada (el “cómo se usa”)
- **Escribir** pequeños programas usando variables y operadores.
- **Leer y escribir** datos desde teclado y hacia la consola.
- **Convertir** tipos de forma segura según la necesidad.
